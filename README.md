# TV Show Marathon Tracker

Assignment 2 - Static Website for Web Development (MDM, University of Coimbra).

## Purpose
The purpose of this website is to let users search for TV shows and calculate the total time it takes to watch all the episodes (marathon time). 

It was built using only standard HTML, CSS, and vanilla JavaScript. All the information and images are fetched dynamically from the public TVMaze API.

## Features
* Search bar to find specific TV shows.
* Details page with synopsis, genres, and rating.
* "Recommended" and "Similar Shows" sections.
* CSS animations (background gradient and hover effects) without any external libraries.
